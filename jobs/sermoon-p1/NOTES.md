# Sermoon P1 — рабочие заметки

Источник: Creality Sermoon P1 3D Scanner Quick Start Guide V1.0, 20 альбомных страниц, EN.

## Сборка
```
.venv/bin/python -m pdft build jobs/sermoon-p1       # харнесс → out/sermoon-p1_RU.pdf
.venv/bin/python jobs/sermoon-p1/legacy/build.py      # старая сборка (июнь 2026) → legacy/out/
```

## История
- Июнь 2026: первый перевод старым движком (закрашивание + ручная геометрия) — `legacy/`.
- 2026-10-27: переделан через харнесс по просьбе пользователя («P1 сильно хуже оформлено»). 145 абзацев взяты из памяти переводов (84 из P1S, 61 из legacy), остальные переведены заново. Аудит (`python -m pdft.audit`), старый → новый: английский текстовый слой 290 → 0 фрагментов, сжатый текст 34 → 0, текст поверх графики 8 → 0, испорченная графика 236 → 0 pt².

## Решения
- Картинки: интерфейс на английском, кнопки названы в тексте → скриншоты не переводятся (`docs/translation-conventions.md`, «Картинки и интерфейс»).
- Термины и оформление приведены к P1S: строчная после двоеточия, «Старт/Пауза», «×» вместо «*», «6. Меры предосторожности» (как в оглавлении).
- Лазеры — короткие формы, как в разделе 3.1 старого перевода: «Одиночный / Параллельный / Перекрёстный лазер»; на тесной схеме стр. 3 — «Паралл. лазер», «Перекр. лазер». В P1S — длинные формы («Лазер параллельных линий»); если нужна единая форма для обоих руководств — решить с пользователем.
- Таблица характеристик: «замеров/с» (measurements/s), «До 0.02 мм», «fps» без перевода. Шапка — «Одна синяя линия / 7 параллельных линий / 22 перекрёстные линии» (полные формы не помещаются).
- «Creality Sermoon P1» в шапке таблицы и «/» в строке процессора остаются как в источнике.

# XM-100 — рабочие заметки

## Сборка
```
python3 hmi/icons.py      # иконки из оригинальных растров → assets/icons
python3 hmi/preview.py    # PNG-превью экранов HMI + сравнение с оригиналом (hmi/out/cmp_*.png)
python3 covers.py         # обложка/задник → assets/cover.pdf, back.pdf
python3 build.py          # content/*.html → XM-100_manual_RU.pdf
```
Плейсхолдеры в content: `<x-hmi n="screen" w="pt"/>`, `<x-btn i="icon" l="Label" [on]/>`, `<x-fig n="svg" w="pt"/>`, `<x-alarms d="A53"/>`, `<!--TOC-->`.

## UI (EN) — принятые надписи
Вкладки: Machining / Tools / Program / System. Режимы: AUTO – Auto / Handwheel Trial / Single Block; JOG – Handwheel / Rapid / Increment; MDI; JOG – ZRN – Home.
Боковая панель: Classic View, Graphic View, Guide View, Edit Program, Control Panel, Help, TSM, Workpiece Positioning, Tool Measure, Clear.
Нижняя панель: All G Codes, G Codes, M Codes, Auxiliary, Switch Coord., Relative Coord., FS Override, Next Page, Select Tool, Select Offset, Single Axis, Cuboid, Cylinder, Tool Setting, Probe Calib.
Прочее: Machine Coord. / Work Coord., Position, Distance to Go, Unit, Status, Tool Info, Feed Rate, Spindle Speed, Tool Length H, Rad. Comp. RS, Tool No. T, Neck End Mill (避空立铣刀), Local NC Files, Machining Guide, Start, Override, Current Tool, Machining Time, Jog Step, Time, Program Control, Tool Positioning, Probe Positioning.
RU-названия: 机械操作面板 = пульт управления; 主机面板 = сенсорная панель; 机床坐标 = система координат станка; 工件坐标 = система координат детали.

## Решения пользователя (2026-10-02)
- Источник: Xhorse XMachine XM-100, 161 стр. A4 (Word 2016, ~38 тыс. иероглифов, оглавление из 128 пунктов в 4 уровня, шрифт Microsoft YaHei). Гл. 1–3 — интерфейс (стр. 11–52, много скриншотов), гл. 4 — G/M-коды (53–111), гл. 5 — таблицы аварий (112–160).
- Текст → русский; интерфейс станка (скриншоты, кнопки, блок-схемы меню) → английский в нашем переводе: официального EN-руководства нет (в центре загрузок xhorse3d.com только ПО и каталог), поэтому надписи могут отличаться от реального станка.
- Скриншоты — полная перерисовка кодом (замену текста в растре пользователь отклонил): HTML/CSS-набор тёмного HMI (`hmi/kit.py`, `kit.css`, `screens.py`), пиктограммы вырезаны из оригинала.
- Таблицы аварий (гл. 5): EN-сообщение как на экране + RU-перевод.
- Число страниц может вырасти; структура и внешний вид сохраняются; кликабельное оглавление и закладки обязательны.
- Перевод в исходную вёрстку не помещается (RU ≈ 2× длиннее ZH), поэтому вёрстка пересобирается: HTML → Chromium PDF → PyMuPDF (закладки, ссылки, водяной знак и логотипы шапки из оригинала: xref 38871, 610, 611). 78 из 204 картинок — «отражения» под кнопками (со SMask), они генерируются из переведённой кнопки.
- Пилот (гл. 2, 3.1, 4.1.1, 5.3) одобрен; полный первый черновик сдан 2026-10-02: 155 стр., 128 закладок.

## Окружение и сборка
- Системный `python3` (miniconda): нужен Playwright с Chromium, которого нет в `.venv` проекта.
- `covers.py` использует пути от текущей папки — запускать из `jobs/xm100/`. Остальные скрипты работают из любой папки.
- `extract/img/` (картинки из исходника, ~28 МБ), `build/` и `hmi/out/` в git не входят; `extract/img/` пересоздаётся `extract/extract.py`.
- При сборке печатается `MuPDF error: format error: Ptr List creation failed` — на результат не влияет (сборка 2026-10-27 совпала с прежней попиксельно).

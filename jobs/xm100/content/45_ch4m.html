4.2 M-коды

4.2.1 Программа

4.2.1.1 Основные операции программы (M00, M01, M02, M30)

M00 — пауза программы; M01 — условная остановка; M02 — конец программы; M30 — конец программы.

Формат

M00;

M01;

M02;

M30;

Пояснение
M00

Пауза программы; автоматическая работа продолжается кнопкой Resume (Продолжить).

После выполнения кадра с M00 автоматическая работа останавливается. При остановке программы сохраняется вся модальная информация; при запуске автоматической работы выполнение продолжается (зависит от производителя станка).

M01

Если включена опция условной остановки, M01 приостанавливает программу; автоматическая работа продолжается кнопкой Resume (Продолжить). Как и M00, после кадра с M01 выполнение программы из памяти останавливается — но только если на пульте станка включён переключатель условной остановки. По умолчанию переключатель условной остановки выключен.

M02

Обозначает конец программы.

Программа завершена; кнопкой Machining (Обработка) программа перезапускается с начала.

M30

Конец программы с возвратом в её начало; кнопкой Machining (Обработка) программа перезапускается с начала.

Ограничения
M02 и M30 вызывают следующее:
  • переключение из режима Auto в режим MDI, сброс системы координат детали;
  • рабочая плоскость — XY; режим размеров — абсолютный;
  • режим подачи — миллиметры в минуту; подходит только для отдельного выполнения;
  • отключение коррекции на радиус инструмента; остановка шпинделя;
  • режим перемещения — G01; отключение охлаждения;
  • автоматическая работа останавливается, и ЧПУ сбрасывается (зависит от производителя станка). После выполнения кадра с концом программы управление возвращается в начало программы.

4.2.1.2 Вызов программы (M98, M99)

M98 — вызов подпрограммы; M99 — M-код для циклического выполнения программы при тестировании.

Формат

M99;

M98 <имя файла программы> L;

L — число повторений

Пояснение
  • M98 — вызов подпрограммы.
  • M99 — конец подпрограммы.
Пример
M98 <100> L1; — однократный вызов программы с именем 100

4.2.2.2 Вращение шпинделя (M03, M04, M05, M19)

M03 — вращение шпинделя по часовой стрелке; M04 — против часовой стрелки; M05 — остановка шпинделя.

M19 — ориентация шпинделя: останов шпинделя в заданном угловом положении.

Формат

M03 S_;

M04 S_;

M05;

S — частота вращения шпинделя.

M19 R_ Q_ [P_];

R — угловое положение, диапазон 0~360°

Q — время ожидания, с (по умолчанию 20)

P — направление поворота: P0 — по кратчайшему углу (по умолчанию); P1 — по часовой стрелке; P2 — против часовой стрелки

Пояснение
  • Если при выполнении M03, M04 частота вращения шпинделя равна 0, шпиндель не вращается; он начинает вращаться, когда S задаёт частоту больше 0.
  • M19 в основном служит для установки шпинделя в определённое угловое положение — чтобы найти начальное положение обработки или выполнить смену инструмента.
Ограничения
  • Отрицательная частота вращения шпинделя вызывает ошибку NC00084.
  • Если после M3/M4 не указан S, возникает ошибка NC00013.
  • Коррекцию частоты вращения шпинделя можно менять ползунком коррекции на экране.
Пример
M03 S1000; — прямое вращение шпинделя, 1000 об/мин
M05; — остановка шпинделя
M04 S2000; — обратное вращение шпинделя, 2000 об/мин
M19 R90; — ориентированный останов шпинделя на 90°

4.2.2.3 Модальное состояние (M70, M72)

M70 — сохранение модального состояния; M72 — восстановление модального состояния.

Формат

M70;

M72;

Пояснение

Если перед M72 не вызывалась M70, возникает ошибка NC30167.

4.2.3 Смена инструмента

M06 — остановка шпинделя, смена инструмента.

Формат

M06 T_;

T — номер инструмента; если не указан, используется инструмент, заданный последним T_.

Пояснение
Команда останавливает шпиндель

M656<T> — смена инструмента из интерфейса;

M6<T> — изменение номера инструмента в шпинделе без движения станка.

Команда не меняет состояние других IO (например, охлаждения)

Команда не задаёт коррекцию на длину инструмента: после M06 задайте длину инструмента привязкой или командой G10.

Ограничения

Отрицательный номер инструмента вызывает ошибку NC00061.

Пример
M06 T1; — смена на инструмент № 1

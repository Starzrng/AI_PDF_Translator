Глава 4. Программирование

4.1 G-коды

4.1.1 Интерполяция

Функции интерполяции задают перемещение осей, то есть траекторию движения инструмента.

4.1.1.1 Позиционирование (G00)

При абсолютном задании G00 на ускоренной скорости перемещает инструмент в заданную точку системы координат детали; при инкрементальном — в точку, смещённую от текущего положения на заданную величину.

Формат

G00 IP;

IP — при абсолютном задании: координаты конечной точки; при инкрементальном: величина перемещения инструмента.

Пояснение
  • Инструмент перемещается в заданную точку по прямой за минимальное время; скорость не превышает скорости ускоренного перемещения каждой оси. Записи G00 и G0 равнозначны.
  • Скорость ускоренного перемещения для G00 задаёт производитель станка. При позиционировании G00 инструмент разгоняется в начале кадра до заданной скорости и замедляется в конце кадра; следующий кадр выполняется только после подтверждения выхода в позицию. Если координаты не указаны, инструмент не движется — система лишь переключает модальный режим перемещения на G00.
Ограничения
  • Скорость ускоренного перемещения нельзя задать адресом F. Значение F в кадре G00 лишь подготавливает подачу резания для последующих кадров обработки.
  • Например: G00 X0 Y10 F500; — перемещение выполняется на ускоренной скорости, заданной в настройках станка.

4.1.1.2 Линейная интерполяция (G01)

Перемещает инструмент по прямой.

Формат

G01 IP_ F_;

IP_ — при абсолютном задании: координаты конечной точки; при инкрементальном: величина перемещения инструмента.

F_ — подача инструмента.

Пояснение
  • Инструмент перемещается по прямой в заданную точку с подачей F. Подача F действует, пока не задано новое значение, — указывать её в каждом кадре не нужно.
  • F — это скорость движения инструмента вдоль прямой. Если F не задана, подача равна нулю.
  • Подача поворотных осей задаётся в град/мин (deg/min).
  • При линейной интерполяции линейной оси α (X, Y, Z) и поворотной оси β (A, B, C) подача F (мм/мин) — это касательная скорость в декартовой системе координат α–β, где A, B, C измеряются в градусах, а X, Y, Z — в мм или дюймах. Скорость оси β находится так: по формулам ниже вычисляется требуемое время, которое затем пересчитывается в град/мин. Скорости по осям:

G01 αα ββ Ff;  L=α2+β2

Скорость по оси α: Fα=αL×f

Скорость по оси β: Fβ=βL×f

Ограничения
  • В режиме подачи в минуту подача не может быть равна 0.
  • В режиме подачи обратно пропорционально времени F нужно указывать в той же строке, иначе возникает ошибка NC00083.
  • Записи G01 и G1 равнозначны.
Пример

Линейная интерполяция: G91 G01 X100.0 Y100.0 F200.0;

Подача поворотной оси: G91 G01 C-80.0 F400.0; — подача 400 град/мин.

Производитель задаёт для каждой оси верхний предел подачи резания F. Если фактическая подача (с учётом коррекции) превышает предел, она ограничивается этим пределом; единица — мм/мин.

Если после G01 координаты не указаны, инструмент не движется — система лишь переключает модальный режим перемещения на G01.

4.1.1.3 Круговая интерполяция (G02, G03)

Перемещает инструмент по дуге в выбранной плоскости.

Формат

Дуга в плоскости XpYp: G17 G02/G03 Xp Yp I J/R F;

Дуга в плоскости ZpXp: G18 G02/G03 Zp Xp I K/R F;

Дуга в плоскости YpZp: G19 G02/G03 Yp Zp J K/R F;

При включении питания по умолчанию действует выбор плоскости G17:

Направление круговой интерполяции

Направления «по часовой стрелке» (G02) и «против часовой стрелки» (G03) для плоскости XpYp (ZpXp, YpZp) определяются при взгляде со стороны положительного направления оси Zp (Yp, Xp) в сторону отрицательного в декартовой системе координат.

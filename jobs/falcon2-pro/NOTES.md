# Falcon2 Pro — рабочие заметки

Источник: Creality Falcon2 Pro (лазерный гравёр), user manual, 33 страницы, EN. Режим: пересборка PyMuPDF — страницы строятся заново, иллюстрации с легендами.

## Сборка
```
.venv/bin/python jobs/falcon2-pro/imgtr.py    → imgs_ru/ (картинка комплекта с русскими подписями)
.venv/bin/python jobs/falcon2-pro/build.py    → out/Falcon2Pro_RU.pdf
```
`content_imgs/` — иллюстрации, вырезанные из исходника; `prose.txt` — текст исходника для справки.

Готово (июнь 2026), 27 страниц.

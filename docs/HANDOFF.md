## 2026-10-27 — харнесс v1 на Sermoon P1S

**Цель пользователя.** Дальняя: сервис перевода PDF лучше существующих. Ближняя: автоматизировать процесс, чтобы адекватный результат получался с минимумом ручного вмешательства (сейчас всё полуручное). Эталон качества — XM-100 (перерисованные векторные экраны). Пользователь параллельно изучает, что такое харнесс и как его строить.

**Слабые места агента со слов пользователя:** термины и кривые фразы; прямоугольные подложки налезают на графику; не перерисовываются некачественные или закрытые иллюстрации; вёрстка — текст слипается, а полстраницы пусто (разные шрифты и длина языков).

**Что сделано.**
- Харнесс `python -m pdft inspect / init / build / review` — устройство в `docs/harness.md`, техника в `docs/overlay-technique.md`.
- Работа `jobs/sermoon-p1s` (23 с., EN): каркас из 217 абзацев, 55 взяты из перевода P1. Пилот — стр. 2, 3, 5, 20: 0 ошибок и 0 предупреждений QA, ждёт одобрения.
- Регрессия старых работ (D1000, Sermoon P1, Falcon2) после изменений ядра — 0.000 %.

**Решения по ходу (мои, пользователю на проверку):**
- Исходный текст удаляется (redaction), а не закрашивается: нет подложек поверх графики, в PDF не остаётся английского текстового слоя.
- При нехватке места блок растёт в свободный фон, а не сжимается; сжатие ниже 90 % — предупреждение агенту.
- Формат данных работы — `translations.py` (как у прежних оверлей-работ), метаданные — `job.json`.

**Находки.**
- MuPDF redaction при относительном позиционировании текста сдвигает строки после удалённого блока (стр. 20 — на 92 pt). Лечится `clean_contents(sanitize=True)` перед удалением; добавлен датчик `moved`.
- Первая версия датчика «подложка на графике» исключала всю рамку исходного текста и пропустила вылезшую под плашку заливку. Теперь все датчики графики сравнивают с рендером исходника без текста.

**Полный перевод P1S (тот же день).** Пилот одобрен; переведены все 23 страницы, QA 0/0, каждая страница просмотрена. По ходу харнесс получил: склейку центрированных строк, повторный `init` без потери переводов, размер шрифта в разметке исходника, межстрочный интервал из исходника, датчики `truncated` и `glyph`, нормализацию извлечённого текста, Medium ≠ жирный.

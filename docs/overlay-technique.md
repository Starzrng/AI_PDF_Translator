# Оверлей: замена текста на месте

Для PDF с извлекаемым текстом, где перевод помещается в исходные блоки. Новые работы — через харнесс `python -m pdft` (образец `jobs/sermoon-p1s`, цикл — `docs/harness.md`). Старые `jobs/d1000-pro-hs` и `jobs/sermoon-p1` собраны своими `build.py` — см. «Старый движок» ниже.

## Харнесс (`pdft/job.py`)

Данные работы: `job.json` (источник, выход, настройки `overlay`), `blocks.json` (`python -m pdft init` создаёт его сам), `translations.py`:

- `t("P5b2", merge=["P5b3", ...], html=..., ...)` — абзац; ключ — первый блок, `merge` — склеенные строки. Части блока из нескольких ячеек/подписей — `P3b10.1`, `P3b10.2`. Необязательные: `size`, `color`, `align`, `lh`, сдвиги `dx0/dy0/dx1/dy1`, абсолютные `x0/x1/y0/y1`, `fr` (зона удаления текста), `grow=False`, `bold`, `paint=True`.
- `op(pg, rect, html, ...)` — текст в явном прямоугольнике (то, чего нет в блоках).
- `keep("P20b2")` — исходный текст, который остаётся как есть.

Сборка: исходный текст под зоной каждой записи удаляется (redaction: только текст, картинки и векторная графика остаются), поэтому подложка не рисуется и ничего не налезает на графику. Затем перевод вписывается `insert_htmlbox` (Arial, `<b>`, `<br>`, `<span style="color:...">`). По умолчанию:

- **жирность** — как у исходного блока, если он целиком жирный;
- **выравнивание** — подпись, прижатая к выноске справа → `right`; к выноске слева → `left`; однострочный текст по центру страницы → `center`; по центру ячейки/рамки → `center`; остальное → `left`;
- **рост вместо сжатия**: если перевод не помещается, блок занимает свободный фон (по рендеру исходника): абзац — вниз, подпись `right` — влево, `center` — в обе стороны, затем вверх-вниз (перенос на 2 строки), `left` — вправо, затем вниз. Вбок — не дальше полей страницы, вниз — не ниже 22 pt от низа.

QA после каждой сборки — список проверок в `pdft/qa.py`; отчёт в `out/qa.json`, геометрия каждой записи — в `out/layout.json`.

## Подводные камни

- **Перед redaction — `page.clean_contents(sanitize=True)`.** Если исходный поток позиционирует текст относительно (`Td`/`TL`), удаление одного блока сдвигает весь текст после него: на sermoon-p1s стр. 20 удаление двухстрочной ячейки подняло три строки таблицы на 92 pt. `build` делает это сам; датчик `moved` ловит такие сдвиги.
- **Однострочному `insert_htmlbox` нужно ~1,15 × (кегль × межстрочный)** по высоте, иначе он сжимает текст даже при свободной ширине.
- **Совпадение с центром страницы** — не признак заголовка: подпись схемы может случайно стоять по центру. Сначала проверяется выноска, потом центр.
- **Плашки заголовков**: свободное место вбок ищется по средней полосе текста — плашка бывает ниже, чем рамка текста.
- **Память переводов приносит чужое форматирование**: у P1 значения таблицы были жирными, у P1S — нет. `init` снимает `<b>`, если исходный абзац не жирный; остальное (цвет, `<br>`) проверять глазами.
- **`subset_fonts()` перед сохранением обязателен**: иначе Arial встраивается целиком на каждую страницу — 116 МБ вместо 9 МБ. `Overlay.save()` делает это сам.
- **Встроенные шрифты оригинала не переиспользуются**: это урезанные подмножества с перекодировкой, кириллицы в них нет. Перевод всегда в Arial.
- **В Arial нет символов вроде ①..⑨ (U+2460+)** — такие фрагменты оставлять в шрифте оригинала (`keep`).
- **Рендер — через `page.get_pixmap`** (`pdft.render`, `pdft review`): poppler из Homebrew на этой машине не ставится.
- **`blocks.json` привязан к версии PyMuPDF** — см. «Жёсткие правила» в `AGENTS.md`.

## Старый движок (d1000-pro-hs, sermoon-p1)

`build.py` работы создаёт `Overlay(...)` и для каждого блока закрашивает его цветом фона (`fill_rect`) поверх оригинального текста, затем вписывает перевод. Исходный текст остаётся в PDF под заливкой (копируется при выделении). Особенности:

- **Заливка ячеек таблиц — внутрь от линий сетки** (`r + (1.4, 1.2, -1.4, -1.2)` или `fr`), иначе в сетке появляются белые разрывы.
- **Перекрывающиеся мелкие выноски — в два прохода**: сначала все заливки, потом весь текст (`OPS` в sermoon-p1).
- **Числа, оставленные без перевода**, sermoon-p1 перерисовывает Arial'ом на страницах таблиц, чтобы шрифт не прыгал.

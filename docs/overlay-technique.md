# Оверлей: замена текста на месте (`pdft.overlay`)

Для PDF с извлекаемым текстом, где перевод помещается в исходные блоки. Образцы: `jobs/d1000-pro-hs` (таблица характеристик, макросы, детали, оглавление), `jobs/sermoon-p1` (явные прямоугольники `OPS`, автоподгон выносок, выравнивание шрифта в таблицах).

## Как устроено

1. `.venv/bin/python -m pdft.blocks jobs/<id>/source.pdf` → `blocks.json` (вход сборки) и `blocks.txt` (читать глазами): блоки текста с bbox, кеглем, цветом.
2. `translations.py` — словарь `TR["P{стр}b{блок}"] = dict(html=..., size=, align=, lh=, ...)`. Подстройка прямоугольника: сдвиги `dx0/dy0/dx1/dy1`, абсолютные `x0/x1/y0/y1`, отдельный прямоугольник заливки `fr`. Таблицы, оглавление и подписи схем — отдельными структурами с явной геометрией; линии сетки берутся из `page.get_drawings()`.
3. `build.py` создаёт `Overlay(source.pdf, sample_step=..., bg_pad=...)`. Для каждого блока `fill_rect` закрашивает его цветом фона (самый частый цвет пикселей в этой области на рендере исходника), `put_html` вписывает перевод через `insert_htmlbox` (Arial через `@font-face`; работают `<b>`, `<br>`, justify). Однострочные подписи — `fit_size` + `put_textbox` с автоподгоном кегля.
4. `ov.save(out)` — `subset_fonts()` и сохранение.

## Подводные камни

- **`subset_fonts()` перед сохранением обязателен**: иначе Arial встраивается целиком на каждую страницу — 116 МБ вместо 9 МБ. `Overlay.save()` делает это сам.
- **Заливка ячеек таблиц — внутрь от линий сетки.** Прямоугольник ячейки с запасом наружу закрашивает тонкие линии, и в сетке появляются белые разрывы. Сдвигать внутрь (`r + (1.4, 1.2, -1.4, -1.2)`) или задавать явный `fr` внутри ячейки; ячейки белые, сдвиг не виден.
- **Перекрывающиеся мелкие выноски — в два прохода**: сначала все заливки, потом весь текст, иначе соседняя заливка стирает уже вписанный текст (`OPS` в sermoon).
- **Встроенные шрифты оригинала не переиспользуются**: это урезанные подмножества с перекодировкой, новый текст ими не рисуется, кириллицы в них нет. Перевод всегда в Arial.
- **Шрифт оставленных чисел.** Числа, которые не переводились, остаются в шрифте оригинала рядом с Arial. Sermoon перерисовывает такие фрагменты Arial'ом только на страницах таблиц: в Arial нет символов вроде ①..⑨ (U+2460+).
- **Тёмные плашки заголовков** обрабатываются автоматически: сэмплер берёт тёмный фон, текст задать белым и по центру.
- **Объединённые ячейки характеристик**: переводить только столбец названий и текстовые значения, числовые оставлять нетронутыми.
- **Рендер — через `page.get_pixmap`** (`pdft.render`): poppler из Homebrew на этой машине не ставится.
- **`blocks.json` привязан к версии PyMuPDF** — см. «Жёсткие правила» в `AGENTS.md`.

# Глоссарий: AlphaPixel «Gaussian Splats»

Решения пользователя от 2026-09-17 (части 1–2). Серия продолжится — сферические гармоники анонсированы в конце части 2, возможно ещё часть про рантайм-рендерер; применять эти решения, не переспрашивая.

- **Gaussian Splat(s) / Gaussian Splatting** — первое упоминание в статье: английский термин с русской расшифровкой, «Gaussian Splats (гауссовы сплаты)», «Gaussian Splatting (гауссовский сплаттинг)». Дальше — «сплат(ы)» и «сплаттинг». Названия алгоритмов и статей не трогать: 3D Gaussian Splatting (как название статьи SIGGRAPH), 3DGS, 2DGS, 4DGS.
- **a Gaussian** (сам примитив, не сплат) → «гауссиана» (мн. «гауссианы», род. мн. «гауссиан») — устоявшаяся форма в русском ML, ср. «смесь гауссиан».
- **bundle adjustment** → «уравнивание связок»; первое упоминание в статье — «уравнивание связок (bundle adjustment)».
- **intrinsics / extrinsics** → «внутренние / внешние параметры камеры» (отклонено: «элементы внутреннего/внешнего ориентирования» — тяжеловато для читателя из CV/ML).
- **Без перевода** (аудитория читает смешанные тексты в стиле Хабра): SfM, MVS, SIFT, RANSAC, PnP, COLMAP, GLOMAP, SSIM/D-SSIM, PSNR, LPIPS, Adam, NeRF (мн. «NeRF'ы»).
- **Устоявшиеся русские термины**: разреженное/плотное облако точек, денсификация, эпиполярная геометрия, дифференцируемый рендеринг, растеризация, альфа-композитинг, ковариация, кватернион, сферические гармоники, обратное распространение, градиентный спуск, переобучение, непрозрачность (opacity — не «прозрачность», это противоположное), сглаживание (anti-aliasing), серфел (surfel), стереобаза/база (baseline).
- **Подписи на схемах** — сокращения допустимы («уравнив. связок», «внутр. параметры»): оригинальные схемы AlphaPixel сами сокращают («PnP + bundle adj.»).

# Правила перевода на русский

Решения пользователя, подтверждённые на работах D1000 Pro HS, Sermoon P1 и XM-100. Глоссарий конкретной работы (`jobs/<id>/NOTES.md`, `docs/glossary/`) главнее этого файла.

## Термины

- filament → «пластик» (не «филамент» и не «пруток»).
- stop / 停止 → «остановка»: аварийная остановка, кнопка аварийной остановки, условная остановка программы (M01). Форму «останов» пользователь считает безграмотной.
- NOTE / TIPS / CAUTION / DANGER → ПРИМЕЧАНИЕ / СОВЕТ / ВНИМАНИЕ / ОПАСНО.

## Когда писать «English (Русский)»

Редко — только для того, что читатель буквально видит и нажимает на английском экране устройства:

- названия экранных кнопок внутри пошаговых инструкций: Preheat, Calibrate, Start, Save, Accept, Z+/Z-, Speed+, Full Measurement…;
- столбцы Type и Usage таблицы макросов; имя макроса (CANCEL_PRINT, M141, T0…) остаётся английским;
- два заголовка Klipper по просьбе пользователя: «Виброгашение (Input Shaper)», «Парковка (HOME)».

Всё остальное — полностью по-русски, без скобок:

- заголовки разделов и названия экранов (Home Page → Главный экран, Bed Mesh → Карта стола, Fine Tuning → Точная настройка) и соответствующие пункты оглавления;
- названия деталей на схемах (Extruder → Экструдер, Heated Bed → Нагревательный стол);
- названия и значения в таблице характеристик;
- обложка: «D1000 Pro HS / Руководство пользователя / V1.0» — без «User Manual».

## Остаётся как в оригинале

Коды продуктов, материалы (PLA, ABS…), единицы, числа, e-mail и URL, G/M-коды, буквы осей и параметров, коды аварий, формулы, примеры программ.

## Картинки и интерфейс: когда переводить

Принцип (решение пользователя, 2026-10-27): **картинку переводим, только если без этого читатель не поймёт, что делать.** Требования переводить каждый скриншот нет. Решение принимается для работы целиком на этапе `inspect` / пилота и записывается в `NOTES.md` работы; спорный случай — вопрос пользователю.

| Ситуация | Что делаем | Прецедент |
|---|---|---|
| Интерфейс на английском, и текст на каждом шаге называет кнопки и пункты, которые показывает иллюстрация | скриншоты **не переводим**; кнопки в тексте — «English» (Русский) по правилу выше | CreatBot D1000, Creality Sermoon P1/P1S |
| Интерфейс на английском, но что нажимать, видно только на картинке (выноски, подписи, стрелки с текстом), а текст этого не говорит | переводим **выноски и подписи поверх скриншота**, сам интерфейс остаётся английским | — |
| Интерфейс на языке, которого читатель не знает (китайский и т. п.) | переводим интерфейс: по официальным EN-названиям, а если их нет — на английский в нашем переводе; скриншоты перерисовываем или меняем в них текст | XM-100: полная векторная перерисовка экранов, сообщения аварий EN + RU, надписи — `jobs/xm100/NOTES.md` |
| Схемы, деталировки, чертежи с подписями (не скриншоты) | подписи **всегда** по-русски, полностью (правило выше) | все работы |
| Растр с важным содержанием в плохом качестве (`inspect`: ниже 200 dpi) | кандидат на перерисовку; решает пользователь | XM-100 |
| Единичные иноязычные фрагменты в английском интерфейсе (кнопка «开始使用» на скриншоте) | не трогаем, если действие описано в тексте; иначе поясняем в тексте | Sermoon P1S, стр. 6–7 |

## Процесс

Проверка с пользователем постранично; что переводить полностью, а что аннотировать, решает пользователь.
